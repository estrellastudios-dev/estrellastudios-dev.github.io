Política de Privacidad

Última actualización: 12 de noviembre de 2026

Esta Política de Privacidad describe qué datos recopila Suggestions Bot (en adelante, "el Bot"), cómo los usa y qué control tienes sobre ellos.

1. Datos que recopilamos

Para proporcionar sus funcionalidades, el Bot almacena los siguientes datos:

Datos de sugerencias y votaciones

  • ID del autor de la sugerencia.
  • Contenido de texto de la sugerencia.
  • ID del mensaje de Discord donde se publicó la sugerencia.
  • Votos positivos y negativos (solo el ID del usuario y el tipo de voto).
  • Estado de la sugerencia (pendiente, aceptada, denegada).
  • Fecha de creación.

Datos de moderación

  • Lista negra (Blacklist): ID de usuario bloqueado, razón y quién lo bloqueó.

Datos técnicos (Logs)

El Bot cuenta con un sistema Anti-Crash que envía informes técnicos (mensajes de error) a un canal privado de Discord mediante Webhooks. Estos logs pueden contener el ID del servidor y del canal donde ocurrió el error, pero no contenido de conversaciones privadas.

2. Cómo usamos los datos

Los datos se usan exclusivamente para:

  • Mantener el sistema de votación persistente (evitar votos duplicados).
  • Actualizar el diseño visual de la sugerencia (barras de progreso).
  • Gestionar la lista negra para prevenir abusos.
  • Depurar errores técnicos para mejorar la estabilidad del Bot.

No usamos los datos para publicidad, perfilado comercial ni venta a terceros.

3. Dónde se almacenan

Suggestions Bot utiliza PostgreSQL (Neon.tech) como servicio de base de datos en la nube para almacenar la información descrita. Neon es un servicio de terceros que aloja los datos en servidores seguros.

Los datos no se envían a servicios externos distintos de:

  • Neon.tech, utilizado exclusivamente como base de datos.
  • La API de Discord, necesaria para el funcionamiento del Bot.

4. Cuánto tiempo se conservan

  • Sugerencias y votos: se conservan indefinidamente para mantener el historial del servidor, a menos que un administrador o el autor solicite su eliminación.
  • Lista negra: hasta que un administrador decida remover al usuario.
  • Logs Anti-Crash: Discord conserva los Webhooks según sus propios términos.

5. Eliminación de datos

Si deseas eliminar una sugerencia que publicaste o tus votos, puedes solicitarlo a través de nuestro servidor de soporte: https://discord.gg/yXWedmuSxE.

Los administradores del servidor también pueden eliminar datos de su servidor eliminando el canal de sugerencias o expulsando al Bot.

6. Menores de edad

Suggestions Bot no está dirigido a menores de 13 años (o la edad mínima legal en tu país). No recopilamos conscientemente datos de menores.
