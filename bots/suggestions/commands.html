👥 Usuarios

/sugerir

Abre un formulario modal para enviar una nueva idea al canal de sugerencias.

🛡️ Administradores

Requieren permisos de Administrador.

/suggestion_accept

Acepta una sugerencia. El mensaje se vuelve verde y se cierran las votaciones.

/suggestion_deny

Deniega una sugerencia. El mensaje se vuelve rojo y se cierran las votaciones.

/suggestion_blacklist_add

Bloquea a un usuario para que no pueda publicar más sugerencias.

/suggestion_blacklist_remove

Remueve a un usuario de la lista negra.
