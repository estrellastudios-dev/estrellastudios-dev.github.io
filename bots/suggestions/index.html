Este bot está diseñado para permitir que tus usuarios propongan ideas y que la comunidad entera participe votando, mientras el staff mantiene el control total de las decisiones.

Ver todos los comandos

¿Cómo funciona?

1. Envía una idea

Cualquier usuario puede usar el comando /sugerir para enviar una propuesta.

2. La comunidad vota

La sugerencia se publica en un canal con botones para Votar a Favor ✅ o Votar en Contra ❌. Los resultados y porcentajes se actualizan en tiempo real.

3. El staff decide

Los administradores revisan la propuesta y pueden usar comandos para Aceptarla (el mensaje se vuelve verde) o Rechazarla (se vuelve rojo), cerrando la votación automáticamente.

Características destacadas

  • Diseño elegante: Las sugerencias se muestran en embeds limpios con barras de progreso para ver el porcentaje de votos.
  • Persistencia total: Los votos se guardan en una base de datos. Si el bot se reinicia, ¡nadie pierde su voto!
  • Anti-Doble Voto: Cada usuario solo puede votar una vez. Si cambia de opinión, el bot actualiza su voto automáticamente.
  • Control de Spam: Incluye un sistema de Lista Negra (Blacklist) para que los administradores puedan bloquear a usuarios que hagan mal uso del sistema.
  • Bilingüe: El bot se adapta al idioma del servidor. Puedes configurarlo en Español o Inglés fácilmente.
  • Roles de Staff Personalizados: Añade roles específicos (además de los Admins) para gestionar sugerencias con /setup-staff.
  • Personalización del Embed: Cambia el color del embed y añade un mensaje sutil al pie con /custom-embed.
  • Modo Chat: Los usuarios también pueden escribir directamente en el canal para sugerir (actívalo con /toggle-chat).
  • Panel de Configuración: Consulta la configuración del bot en tu servidor de un vistazo con /config.
  • Reinicio Seguro: Empieza de cero sin perder las sugerencias ni la lista negra con /reset-setup.
